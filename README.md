# granulation_boundaries
Example python scripts for segmenting images of solar granulation.

The examples use publicly available radiative MHD simulation data produced as 
part of the SPIN4D project; see https://ifauh.github.io/SPIN4D/ and 
https://github.com/ifauh/spin4d-data.

Some of the boundary tracing I shamelessly stole from 
https://github.com/theobdt/boundary_tracing, who I think wrote it up to trace 
segments in butterfly wings, which is super cool!  So, go check out their
work, too.
